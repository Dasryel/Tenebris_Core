## A brief description of how generative AI supported my work, with encountered limitations:

Github offered to get the project up to speed with an agent. I wrote a description for the task and gave the agent a go - never tried one before, wanted to try it. It generated a readme and folder structure as PR, as requested. 

In addition to code LLM can generate responses to my ideas and questions, they can be helpful in understanding what my options could be. It would be good to find answers to questions myself by reading documents, books etc. but as a personal limitation I am sometimes lazy and taking shortcuts is easy.

Another limitation is that LLM usually generates too long responses, they take too long to read, LLM is bad at distilling/summarizing the essential information so it generates a lot of text to cover that.
